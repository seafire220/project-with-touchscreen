  AppImage runtime".

WHAT IT DOWNLOADS THE FIRST TIME IT STARTS

The first start downloads Character Studio's AI tools onto this computer, from their authors' own pages:
Python packages from the Python Package Index (PyTorch from the PyTorch project's own server), and the
See-through part-finding code and model from its authors' GitHub and Hugging Face pages. They are not
part of the app. Each comes with its own licence, listed on this page as installed on this computer.
On a computer with an NVIDIA graphics card, PyTorch's version for it is downloaded, with NVIDIA's CUDA
libraries under NVIDIA's own licence terms.
